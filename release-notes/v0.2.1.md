# ScienceX v0.2.1 — 三平台发布修复与国内服务商预设 / Release Fixes & Domestic Provider Presets

---

## v0.2.1 的重点 / What's in v0.2.1

**中文：**

v0.2.1 是 v0.2.0 的后续修复版本，解决了首版发布工作流在 Windows 平台的阻塞问题，并新增了国内模型服务商预设：

- **修复 Windows 构建阻塞**：`Verify packaged app structure` 步骤使用 `ls -la`（Unix 语法），在 Windows PowerShell runner 上报错。改为显式 `shell: bash` 跨平台执行。
- **修复 Windows 安装包冒烟测试**：`windows-installer-smoke.ps1` 调用缺少必填的 `-ArtifactsDir` 参数，补充传入 `build-artifacts/electron`。
- **修复 Sidecar 编译依赖解析**：4 个 IM adapter SDK（baileys / lark-sdk / grammy / dingtalk-stream）声明在 `adapters/package.json` 而非根 workspace，CI 的 release build 只在根目录 `bun install` 导致 Bun.build 解析失败。已加入 `external` 列表。
- **允许未签名的 tag 触发发布**：`signing-preflight` 在缺少 macOS 签名密钥时不再 `exit 1`，改为降级为 unsigned 构建 + 警告，让无 Apple 开发者证书的维护者也能发布。
- **新增国内服务商预设**：阿里云百炼（DashScope，qwen3.7-max / qwen3.6-flash）和火山方舟（Volcengine Ark Coding Plan，doubao-seed-code-preview-latest），均为 Anthropic 兼容端点 + auth_token 鉴权，直连 ScienceX。
- **README 增强**：增加 macOS / Windows / Linux 三平台下载徽章和格式说明表格，顶部加入中英文切换链接。

---

**English:**

v0.2.1 is a follow-up fix release for v0.2.0, resolving Windows-platform blockers in the first release workflow and adding domestic model provider presets:

- **Fix Windows build blocker**: the `Verify packaged app structure` step used `ls -la` (Unix syntax) which fails on Windows PowerShell runners. Switched to explicit `shell: bash` for cross-platform execution.
- **Fix Windows installer smoke test**: `windows-installer-smoke.ps1` was invoked without the mandatory `-ArtifactsDir` parameter. Now passes `build-artifacts/electron`.
- **Fix sidecar build dependency resolution**: 4 IM adapter SDKs (baileys / lark-sdk / grammy / dingtalk-stream) are declared in `adapters/package.json` not the root workspace. CI release builds only run `bun install` at the repo root, causing Bun.build to fail resolution. Added to the `external` list.
- **Allow unsigned tag-triggered releases**: `signing-preflight` no longer `exit 1` when macOS signing secrets are missing on a tag push — it degrades to unsigned build with a warning, letting maintainers without an Apple Developer certificate publish releases.
- **Add domestic provider presets**: Aliyun DashScope (qwen3.7-max / qwen3.6-flash) and Volcengine Ark Coding Plan (doubao-seed-code-preview-latest), both Anthropic-compatible endpoints with auth_token strategy, direct-connect to ScienceX.
- **README enhancements**: added macOS / Windows / Linux download badges with format table, and a language switch link at the top.

## 首次安装说明 / First-Time Installation

### macOS

安装包未签名，系统会拦截。提示「已损坏」或「无法验证开发者」时，终端执行：

*The installer is unsigned; macOS will block it. When you see "damaged" or "cannot verify developer," run in terminal:*

```bash
xattr -cr /Applications/ScienceX.app
```

### Windows

未签名安装包会出现 SmartScreen 提示，点击「更多信息」→「仍要运行」即可。

*Unsigned installers trigger SmartScreen. Click "More info" → "Run anyway."*

### Linux

```bash
sudo dpkg -i sciencex_*.deb
# 或运行 AppImage
chmod +x ScienceX-*.AppImage
./ScienceX-*.AppImage
```
