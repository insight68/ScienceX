# ScienceX v0.2.3 — Windows 安装包冒烟测试与桌面测试稳定性 / Windows Installer Smoke & Desktop Test Stability

---

## v0.2.3 的重点 / What's in v0.2.3

**中文：**

v0.2.3 修复了 Windows 平台 CI 阻塞和桌面测试超时问题：

- **修复 Windows 安装包冒烟测试参数传递**：在 pwsh 默认 shell 中嵌套调用 `powershell -File script.ps1 -ArtifactsDir value` 时，pwsh 的原生命令参数解析会吞掉 `-ArtifactsDir`，导致脚本报 "missing mandatory parameters: ArtifactsDir"。改为 `shell: pwsh` 直接运行 `./scripts/windows-installer-smoke.ps1 -ArtifactsDir build-artifacts/electron`，参数绑定在单一 PowerShell 作用域内完成。
- **修复桌面端测试超时**：`WorkspaceDiffSurface.test.tsx` 中两个测试在 jsdom 中渲染 5001 行和 ~1996 行 diff 内容，默认 5000ms 超时在 CI runner 上不足。将 `vitest.config.ts` 的 `testTimeout` 提升到 15000ms（3 倍默认值）。

---

**English:**

v0.2.3 fixes Windows CI blockers and desktop test timeouts:

- **Fix Windows installer smoke test parameter passing**: nesting `powershell -File script.ps1 -ArtifactsDir value` inside a pwsh default shell caused pwsh's native command argument parsing to swallow `-ArtifactsDir`, making the script report "missing mandatory parameters: ArtifactsDir". Switched to `shell: pwsh` running `./scripts/windows-installer-smoke.ps1 -ArtifactsDir build-artifacts/electron` directly, keeping parameter binding within a single PowerShell runspace.
- **Fix desktop test timeouts**: two tests in `WorkspaceDiffSurface.test.tsx` render 5001 and ~1996 lines of diff content in jsdom; the default 5000ms timeout was insufficient on CI runners. Raised `testTimeout` in `vitest.config.ts` to 15000ms (3x default).

## 首次安装说明 / First-Time Installation

### macOS

安装包未签名，系统会拦截。提示「已损坏」或「无法验证开发者」时，终端执行：

*The installer is unsigned; macOS will block it. When you see "damaged" or "cannot verify developer," run in terminal:*

```bash
xattr -cr /Applications/ScienceX.app
```

### Windows

未签名安装包会出现 SmartScreen 提示，点击「更多信息」→「仍要运行」即可。

*Unsigned installers trigger SmartScreen. Click "More info" → "Run anyway."*

### Linux

```bash
sudo dpkg -i sciencex_*.deb
# 或运行 AppImage
chmod +x ScienceX-*.AppImage
./ScienceX-*.AppImage
```
