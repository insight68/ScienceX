# ScienceX v0.2.5 — Sidecar 编译稳定性与 CI Coverage 门禁修复 / Sidecar Build Stability & CI Coverage Gate Fix

---

## v0.2.5 的重点 / What's in v0.2.5

**中文：**

v0.2.5 修复了 sidecar 编译时的模块解析失败和 CI coverage 门禁的两个阻塞问题：

- **修复 sidecar 编译时的可选 SDK 模块解析错误**：所有 IM 适配器（飞书、Telegram、钉钉、WhatsApp）中的可选 SDK（`@larksuiteoapi/node-sdk`、`grammy`、`dingtalk-stream`、`@whiskeysockets/baileys`）从静态值 import 改为 `import type` + 函数内动态 `await import()`。Bun 编译 sidecar 时不再将这些可选依赖打包进 bundle，运行时未安装 SDK 也不会崩溃，仅在真正启动对应适配器时按需加载。
- **修复 CI coverage-checks 缺少子工作区依赖**：`pr-quality.yml` 中的 `coverage-checks` job 只安装了根目录依赖，导致 adapters 和 desktop 测试套件因缺少 `node_modules` 全部失败。补充 `cd adapters && bun install --frozen-lockfile` 和 `cd desktop && bun install --frozen-lockfile` 步骤。
- **修复 coverage 模式下桌面测试超时**：`WorkspacePanel.test.tsx` 中"展开长文件预览"测试渲染 2300 行代码，在 coverage instrumentation 开销下超过 20s 超时。将 coverage gate 的 `testTimeout` 和该测试的超时从 20s 提升到 30s。

---

**English:**

v0.2.5 fixes sidecar compilation module resolution failures and two CI coverage gate blockers:

- **Fix sidecar optional SDK module resolution errors**: all IM adapters (Feishu, Telegram, DingTalk, WhatsApp) now use `import type` + in-function dynamic `await import()` for their optional SDKs (`@larksuiteoapi/node-sdk`, `grammy`, `dingtalk-stream`, `@whiskeysockets/baileys`) instead of static value imports. Bun no longer bundles these optional dependencies when compiling the sidecar; missing SDKs at runtime no longer crash the process, and are only loaded on-demand when the corresponding adapter actually starts.
- **Fix CI coverage-checks missing sub-workspace dependencies**: the `coverage-checks` job in `pr-quality.yml` only installed root dependencies, causing adapters and desktop test suites to fail entirely due to missing `node_modules`. Added `cd adapters && bun install --frozen-lockfile` and `cd desktop && bun install --frozen-lockfile` steps.
- **Fix desktop test timeout under coverage instrumentation**: the "expand long file previews" test in `WorkspacePanel.test.tsx` renders 2300 lines of code and exceeded the 20s timeout under coverage instrumentation overhead. Raised both the coverage gate's `testTimeout` and the test's own timeout from 20s to 30s.

## 首次安装说明 / First-Time Installation

### macOS

安装包未签名，系统会拦截。提示「已损坏」或「无法验证开发者」时，终端执行：

*The installer is unsigned; macOS will block it. When you see "damaged" or "cannot verify developer," run in terminal:*

```bash
xattr -cr /Applications/ScienceX.app
```

### Windows

未签名安装包会出现 SmartScreen 提示，点击「更多信息」→「仍要运行」即可。

*Unsigned installers trigger SmartScreen. Click "More info" → "Run anyway."*

### Linux

```bash
sudo dpkg -i sciencex_*.deb
# 或运行 AppImage
chmod +x ScienceX-*.AppImage
./ScienceX-*.AppImage
```
