# 开始使用 ScienceX

ScienceX 是开源、本地优先的科研孪生实验台。第一次使用，建议先了解[科研孪生的产品定位与能力边界](./research-twin-workbench.md)，再通过 3 分钟教学案例完成一次从研究对象、数据版本到分析产物和重放验证的数字实验孪生流程。

## 第一次使用建议

1. 下载并启动桌面版。
2. 打开左侧 **Science**，运行内置教学案例；该案例使用本机生成的模拟数据，不需要模型凭据。
3. 检查研究问题、输入版本、运行记录和生成的研究产物。
4. 需要 AI 对话时，再在 **设置 → Providers** 中配置模型提供商。
5. 用自己的研究目录创建项目，并从一个范围明确、结果可核对的任务开始。

> **本地优先不等于完全离线。** 本地实验分析不会把表格内容发送给模型；使用远程模型时，请求所需的提示词、上下文和工具结果会发送到你配置的服务端点。请先确认提供商的数据处理政策和授权范围。
